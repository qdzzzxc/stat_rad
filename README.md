# stat_rad

Оцифрованные конспекты курса «Основы статистической теории обнаружения сигналов и распознавания образов в искусственном интеллекте» (МГТУ им. Н. Э. Баумана).

Рукописные сканы превращены в Markdown с формулами и графиками. Из Markdown собираются автономные HTML-страницы для чтения с телефона и PDF для печати.

## Читать

Готовые страницы лежат в [`html/`](html/) и [`pdf/`](pdf/): HTML можно открыть в браузере без интернета, PDF — читать или печатать.

| Файл | Что внутри |
|---|---|
| [notes.html](html/notes.html) | Полный конспект, 15 лекций на одной странице с оглавлением: случайные процессы и их преобразования, оптимальный приём, обнаружение, различение и измерение параметров сигналов |
| [lec01.html](html/lec01.html) | Лекция 1 из отдельного скана: случайные процессы, функции распределения, плотность вероятности, моментные функции |
| [lec02.html](html/lec02.html) | Лекция 2 из отдельного скана: стационарность, эргодичность и корреляция случайных процессов |

PDF-версии: [полный конспект](pdf/notes.pdf), [лекция 1](pdf/lec01.pdf), [лекция 2](pdf/lec02.pdf).

## Структура

```
raw/                           сканы конспектов (PDF, Git LFS)
lectures/lec01/, lec02/        отдельные сканы: lecNN.md + fig/*.svg
lectures/notes/index.md        полный конспект: заголовок и вступление
lectures/notes/lecNN/lecNN.md  лекции полного конспекта (+ fig/*.svg)
html/                          собранные страницы
pdf/                           PDF для чтения и печати
build.mjs                      сборка md → html и pdf
```

## Сборка

Нужны [uv](https://docs.astral.sh/uv/) и Node.js. Для PDF Chromium устанавливается через Playwright.

```bash
uv sync          # pymupdf, pillow — рендер сканов и скриншоты
npm ci
npx playwright install chromium --no-shell  # один раз
npm run build    # все лекции и летучки → html/ и pdf/
```
