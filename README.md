# stat_rad

Оцифрованные конспекты курса «Основы статистической теории обнаружения сигналов и распознавания образов в искусственном интеллекте» (МГТУ им. Н. Э. Баумана).

Рукописные сканы превращены в Markdown с формулами и графиками. Из Markdown собираются автономные HTML-страницы, удобные для чтения с телефона: без интернета, со светлой и тёмной темой.

## Читать

Готовые страницы лежат в [`html/`](html/): скачайте файл и откройте в браузере.

| Лекция | Тема |
|---|---|
| [1](html/lec01.html) | Начала статистической радиотехники: случайные процессы, функции распределения, плотность вероятности, моментные функции |

## Структура

```
raw/                       сканы тетради (PDF)
lectures/lecNN/lecNN.md    исходник лекции
lectures/lecNN/fig/*.svg   графики
html/lecNN.html            собранная страница
build.mjs                  сборка md → html
```

## Сборка

Нужны [uv](https://docs.astral.sh/uv/) и Node.js.

```bash
uv sync          # pymupdf, pillow — рендер сканов и скриншоты
npm ci           # marked, katex
npm run build    # все lectures/*/lecNN.md → html/
```
