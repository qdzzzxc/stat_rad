# stat_rad

Оцифрованные конспекты курса «Основы статистической теории обнаружения сигналов и распознавания образов в искусственном интеллекте» (МГТУ им. Н. Э. Баумана).

Рукописные сканы превращены в Markdown с формулами и графиками. Из Markdown собираются автономные HTML-страницы для чтения с телефона и PDF для печати.

## Читать

Готовые страницы лежат в [`html/`](html/) и [`pdf/`](pdf/): HTML можно открыть в браузере без интернета, PDF — читать или печатать.

**Книга для понимания, лекции 1–4 из отдельных сканов:** [HTML с оглавлением](html/readings/book.html), [PDF](pdf/readings/book.pdf), [единый исходник](readings/book.md). «Статистическая радиотехника: понятия и смысл» — связное изложение с определениями, основными формулами и пояснениями, без развёрнутых доказательств и повторных вычислений. HTML и PDF хранятся в Git LFS.

**Ответы к тестам, лекции 1–3:** [HTML с оглавлением](html/quizzes/tests.html), [PDF](pdf/quizzes/tests.pdf), [единый исходник](quizzes/tests.md). Десять коротких ответов по вопросам группы, без доказательств и формул. Новые вопросы добавляются в тот же файл под соответствующей лекцией. В свойствах нормированной корреляции затухание указано с условием; в определении СПМ сохранено различие ковариационной и корреляционной функций из лекций.

## Сборка

Нужны [uv](https://docs.astral.sh/uv/) и Node.js. Для PDF Chromium устанавливается через Playwright.

```bash
uv sync          # pymupdf, pillow — рендер сканов и скриншоты
npm ci
npx playwright install chromium --no-shell  # один раз
npm run build    # все лекции и летучки → html/ и pdf/
node build.mjs readings/book.md  # только книга → HTML и PDF
node build.mjs quizzes/tests.md  # только ответы к тестам → HTML и PDF
```

Для установленного отдельно Chromium можно задать `CHROMIUM_EXECUTABLE_PATH` — путь к исполняемому файлу браузера.

Материалы из `quizzes/` с заголовком первого уровня собираются с оглавлением: заголовки второго уровня обозначают лекции, третьего — вопросы. В PDF разделы идут подряд; страницы нумеруются.

## Редакционные пояснения к книге

Книга перерабатывает отдельные лекции 1–4, сохраняя обозначения и определения. Изменения относительно полного переноса:

- Убраны доказательства свойств корреляции и линейной зависимости, раскрытия скобок, повторные интегральные записи моментов, разложение двумерной гауссовской плотности и вычислительная запись многомерной плотности через определитель и алгебраические дополнения. Сохранены результаты и смысл совместного гауссовского распределения.
- Формальное обозначение функциональной плотности траектории заменено объяснением через семейство совместных распределений. Классификация процессов сохранена словами; рисунки выбраны для пояснения основных связей.
- Из критериев эргодичности оставлен критерий по среднему с указанием среднеквадратического смысла. Записи критериев по дисперсии и корреляции из лекции 2 с неоговорёнными предпосылками не воспроизводятся; сохранено различие эргодичности по этим характеристикам.
- Добавлены поясняющие примеры и условия: стационарный, но неэргодический процесс с постоянной случайной амплитудой; конечные вторые моменты для широкой стационарности; равномерная случайная фаза для приведённой периодической корреляции; ненулевые знаменатели при нормировании.
- Уточнено, что плотность не равна вероятности точного значения, отсутствие корреляции не означает независимость, а гауссовость процесса требует совместной гауссовости отсчётов. Для нормальной функции распределения добавлена стандартная запись через Φ((x−m)/σ).
- Указана бесконечная мощность идеального белого шума, соглашение о двухстороннем спектре и отличие среднего квадрата от мощности в ваттах. Сохранено исходное определение эффективной ширины спектра.
- У свёртки и частотной характеристики явно указана неизменность параметров системы во времени. Причинность отделена от затухания отклика; затухание само по себе не объявляется достаточным условием устойчивости.
- Уточнены условия нормализации и разложения характеристической функции по моментам. Сравнение полос не объявляется достаточным условием гауссовского выхода, а несколько первых моментов — достаточным описанием произвольного распределения.
