# Оцифровка конспекта: raw/*.pdf → lectures/lecNN/lecNN.md → html/lecNN.html

## Структура проекта

```
raw/                     сканы (Adobe Scan, без текстового слоя)
lectures/lecNN/lecNN.md  исходник лекции
lectures/lecNN/fig/*.svg графики, нарисованные вручную
html/lecNN.html          результат: один автономный файл (KaTeX, шрифты и SVG встроены)
build.mjs                сборка md → html
```

Окружение: `uv sync` (pymupdf и pillow из `pyproject.toml`) и `npm ci` (marked, marked-katex-extension, katex). Python запускать только через `uv run`.

## 1. Посмотреть страницы

Read не открывает PDF без poppler, поэтому сначала отрендери страницы в PNG в scratchpad:

```bash
uv run .claude/skills/digitize-notes/scripts/render_pages.py "raw/<файл>.pdf" <scratchpad>/pages
```

Потом прочитай **все** страницы через Read, одним сообщением параллельно. Если место неразборчиво, отрендери с `dpi=200` и посмотри ещё раз.

## 2. Набрать текст вручную

**Распознавай сам, глазами.** Никакого OCR, tesseract и скриптового извлечения текста: пользователь прямо просил смотреть нативно и писать руками. Python нужен только для рендера страниц и скриншотов.

- Сокращения из тетради раскрывай: СП, ОВЗ и СФ оставь (при первом появлении расшифруй), а «хар-ка», «вер-ти», «ф-я», «∀», «м/б» пиши словами.
- Явные описки в формулах исправляй: перепутанные $x$ и $t$ в аргументах, пропущенные $dx$. Смысл не меняй.
- **Обозначения переноси как в конспекте.** Не заменяй их «учебными», даже если в литературе принято иначе: пользователь просил ровно как в тетради. Если сомневаешься, какая буква, увеличь фрагмент (`pymupdf` `get_pixmap(dpi=200, clip=Rect)`) и посмотри. Уже установлено в лекции 1:
  - характеристическая функция — $Q$, $Q_2$, $Q_n$ (у одномерной индекса нет);
  - начальные моменты — $M_{i_1\ldots i_n}$, $M_1$, $M_{11}$, $M_2$ (обычная M, как у оператора $M\{\cdot\}$);
  - центральные моменты — $\mu_{i_1\ldots i_n}$: в тетради это M с хвостиком вниз слева, так от руки пишется μ;
  - матожидание — строчная $m_x(t)$, $m_1$.

  Держи обозначения едиными с прошлыми лекциями в `lectures/`.
- Если место неразборчиво даже при увеличении, пиши лучшую догадку и помечай `*(неразборчиво)*`.
- Все отклонения от тетради (обозначения, исправленные описки, догадки) перечисли пользователю в финальном ответе.

### Формат md

```markdown
# <Название курса>            ← только в первой лекции; в следующих можно опустить
*Лектор: ...*
## Лекция N. <Тема>           ← первый `##` становится <title> страницы
## <Раздел>  /  ### <Подраздел>
```

- Определения: термин **жирным**, дальше «— …». Замечания лектора («!», аналогии) оформляй цитатой `>`.
- Формулы: `$...$` в строке, `$$ ... $$` отдельным блоком (каждый `$$` на своей строке).
- **Ширина телефона.** Строка выключной формулы должна быть не длиннее примерно 40 знаков видимого текста. Длинные разбивай так:

```latex
$$
\begin{aligned}
&Q_2(ju_1, ju_2; t_1, t_2) = M\{e^{j(u_1 x_1 + u_2 x_2)}\} = \\
&= \iint_{-\infty}^{+\infty} e^{j(u_1 x_1 + u_2 x_2)} \times \\
&\qquad \times W_2(x_1, x_2; t_1, t_2)\, dx_1\, dx_2
\end{aligned}
$$
```

  `&` ставь в начале каждой строки (выравнивание по левому краю), продолжение начинай с `&= `, разрыв произведения оформляй как `\times \\ &\qquad \times`. Кратный интеграл пиши как `\underbrace{\int \!\cdots\! \int_{-\infty}^{+\infty}}_{n}`.
- Рисунок ставь отдельным абзацем: `![Рис. N. Подпись](fig/NN-name.svg)`. Сквозная нумерация внутри лекции.

## 3. Нарисовать графики (SVG вручную)

Каждый график из тетради перерисовывай руками как SVG-файл: пиши координаты и пути сам, без matplotlib и генераторов. Это аккуратная схема по смыслу рисунка, а не точная копия: оси со стрелками, подписи, выделенная кривая.

Шаблон (образцы лежат в `lectures/lec01/fig/`):

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 320 170" font-family="Georgia, serif" font-size="13" fill="none" stroke="currentColor" stroke-width="1.6" color="#1f2937">
  <defs><marker id="aNN" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto"><path d="M0 0L10 5L0 10z" fill="currentColor" stroke="none"/></marker></defs>
  <line x1="30" y1="140" x2="308" y2="140" marker-end="url(#aNN)"/>   <!-- ось t -->
  <line x1="30" y1="140" x2="30" y2="12" marker-end="url(#aNN)"/>     <!-- ось y -->
  <path class="acc" stroke="#2b59c3" stroke-width="2.2" d="M30 110C50 60 65 50 80 80S105 130 125 90"/>
  <text x="304" y="160" fill="currentColor" stroke="none" font-style="italic">t</text>
</svg>
```

Правила:
- Ширина `viewBox` около 320–340, высота по содержимому. Иначе на телефоне всё будет мелким.
- Основной цвет задавай через `currentColor`. Акцент (главная кривая, точки, подпись огибающей) — `class="acc"` для stroke или `class="accf"` для fill, плюс запасной `stroke`/`fill="#2b59c3"`. При сборке цвета берутся из темы: светлой или тёмной.
- **id маркера уникален на всю лекцию** (`a01`, `a02`, …), потому что все SVG встраиваются в одну страницу.
- Не используй надстрочные Unicode-символы вроде `⁽¹⁾` или `ᴺ`: в шрифтах их нет. Верхний индекс делай так: `x<tspan dy="-5" font-size="9">(1)</tspan><tspan dy="5">(t)</tspan>`. Подстрочные `t₁ t₂` отображаются нормально.
- Синусоиду удобно собирать цепочкой `Q` по полупериодам: пик кривой лежит на половине пути до контрольной точки, поэтому для амплитуды A ставь контрольную точку на 2A от оси.
- Подписи не должны налезать на кривые. Это проверяется только на скриншоте (шаг 5).

## 4. Собрать

```bash
node build.mjs lectures/lecNN/lecNN.md   # или без аргументов: все лекции
grep -c 'katex-error' html/lecNN.html    # должно быть 0
```

## 5. Проверить глазами на ширине телефона

```bash
.claude/skills/digitize-notes/scripts/phone_shots.sh html/lecNN.html <scratchpad>/shots
.claude/skills/digitize-notes/scripts/phone_shots.sh html/lecNN.html <scratchpad>/shots dark
```

Прочитай все куски `light*.png` и хотя бы те `dark*.png`, где есть графики. Что проверять:
- формулы не обрезаны справа (обрезанные разбей по правилам шага 2);
- на графиках нет наложений и квадратиков вместо символов;
- в тёмной теме всё видно.

Исправь, пересобери и проверь снова.

## 6. Ответ пользователю

Коротко: что оцифровано, путь к `html/lecNN.html`, какие графики нарисованы, и список отклонений от тетради.
