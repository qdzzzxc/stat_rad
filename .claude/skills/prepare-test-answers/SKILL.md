# Ответы к тестам по лекциям

## Источники и место в проекте

- Основной сборник — `quizzes/tests.md`. Дополняй его вопросами под соответствующими лекциями; не создавай отдельный файл на каждый вопрос или лекцию без запроса пользователя.
- Бери материал из указанных пользователем лекций. Для отдельных сканов это `lectures/lecNN/lecNN.md`; серию `lectures/notes/` используй, если пользователь выбрал именно её. `readings/book.md` может помочь с объяснением, но формулы сверяй с полной оцифровкой.
- Если нужного фрагмента нет в Markdown, работай со сканом по скиллу `digitize-notes`: глазами, без OCR. Не подменяй отсутствующий материал общим учебником.
- Сохраняй порядок и смысл вопросов пользователя. Не добавляй темы вне списка.

## Короткий ответ с формулой

Дай определение или результат, ключевую формулу и краткий смысл. Обычно достаточно одного-двух предложений и одного блока формул. Для классификаций и перечней свойств удобен список. Формула не нужна там, где она ничего не добавляет, например в перечне областей определения и значений.

- Формулы разрешены и ожидаются: `$...$` в строке, `$$` на отдельных строках для выключных формул. Используй LaTeX, совместимый с KaTeX проекта.
- Не включай доказательства, последовательное раскрытие скобок и повторные записи одной формулы через несколько интегралов, если их не спрашивали.
- Сохраняй необходимые условия рядом с результатом: действительный стационарный процесс, конечные моменты, ненулевая дисперсия, затухание корреляции и т. п. Не выдавай условное свойство за универсальное.
- Сохраняй обозначения курса: ожидание `M{…}`, среднее $m_x(t)$, начальные моменты $M_{i_1\ldots i_n}$, центральные $\mu_{i_1\ldots i_n}$, характеристическая функция $Q$.
- В этом курсе $K_x$ — ковариационная функция, **нецентрированный** второй момент; $R_x$ — корреляционная функция, **центрированный** второй момент. В определении СПМ используется $K_x$; для центрированного процесса $K_x=R_x$. Не меняй названия на принятые в другом учебнике.
- Длинные формулы разбивай через `aligned`, сохраняя читаемые строки на ширине телефона. Поясняй новые обозначения рядом с формулой.
- Рисунок добавляй только если он заметно облегчает ответ; переиспользуй SVG из соответствующей лекции относительной ссылкой.

## Структура и сборка

В `quizzes/tests.md` используй один `# Ответы к тестам по статистической радиотехнике`, `## Лекция N` и `### N Название вопроса`. Сборщик создаёт оглавление из этих заголовков; вручную его не дублируй.

```bash
node build.mjs quizzes/tests.md
```

Результат — `html/quizzes/tests.html` и `pdf/quizzes/tests.pdf`. HTML автономен, в PDF есть ссылки оглавления и номера страниц. Если Playwright Chromium отсутствует, можно задать `CHROMIUM_EXECUTABLE_PATH` для установленного браузера. Не редактируй результаты сборки вручную.

После правок пересобери оба формата. Проверь формулы и оглавление на ширине телефона в светлой и тёмной теме, а PDF — глазами после рендера страниц. Исправь обрезанные формулы и заголовки, оторванные от ответов. Python запускай через `uv run`.

HTML и PDF отслеживаются Git LFS по существующим правилам `.gitattributes`. При разрешённом пользователем коммите проверь, что в индексе лежат LFS-указатели; сам скилл не даёт разрешения на коммит или пуш.

В ответе пользователю дай ссылки на общий HTML и PDF и кратко перечисли существенные уточнения относительно лекции, если они потребовались.
