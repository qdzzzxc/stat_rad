# stat_rad — оцифровка конспектов по статрадиотехнике

Рукописные конспекты курса «Основы статистической теории обнаружения сигналов и распознавания образов в искусственном интеллекте» (лектор Нефёдова Ю. С., МГТУ). Скан превращается в Markdown с формулами и SVG-графиками, а из него собираются автономный HTML для чтения с телефона и PDF для печати.

## Структура

```
raw/                              сканы конспектов (PDF без текстового слоя; хранятся в Git LFS)
lectures/lec01/                   лекция 1 из отдельного скана «лек 1 статрад.pdf»
lectures/notes/index.md           серия «Стат. Рад. Лекции.pdf»: заголовок курса и вступление
lectures/notes/lecNN/lecNN.md     лекции серии: текст + формулы KaTeX, графики в fig/
quizzes/quizNN.md                 материалы к летучкам: выжимка из лекций, рисунки берутся из lectures/…/fig
quizzes/tests.md                  общий сборник ответов к тестам с формулами
html/lecNN.html, html/notes.html  результат сборки; руками не править, но коммитить
html/quizzes/quizNN.html          сборка летучек
pdf/                              PDF тех же материалов; руками не править, но коммитить
build.mjs                         сборка md → html и pdf (KaTeX пререндер, шрифты и SVG встроены)
.claude/skills/                   скиллы; .agents/skills — симлинк на них для Codex
```

## Окружение

- Python только через **uv**: `uv sync`, скрипты запускать как `uv run <script>`. Не использовать `pip` и `.venv/bin/python` напрямую; зависимости добавлять через `uv add`.
- Node: `npm ci`; для PDF установить Chromium через `npx playwright install chromium --no-shell`. Сборка всего — `npm run build`; отдельной лекции — `node build.mjs lectures/lec02`; серии — `node build.mjs lectures/notes`; летучки — `node build.mjs quizzes/quiz01.md`.
- Git LFS: `*.pdf` и `html/**/*.html` отслеживаются через LFS (`.gitattributes`); после клона нужен `git lfs install`.
- Проверка на ширине телефона: `.claude/skills/digitize-notes/scripts/phone_shots.sh` (нужен chrome-headless-shell из `~/.cache/ms-playwright`).

## Оцифровка лекции

Порядок работы описан в скилле **digitize-notes** (`.claude/skills/digitize-notes/SKILL.md`), следуй ему. Главные правила:

- **Распознавать глазами.** Страницы рендерятся в PNG и читаются как изображения, текст и формулы набираются вручную. Никакого OCR и скриптового извлечения текста.
- **Обозначения — как в тетради**, не заменять на учебные: характеристическая функция $Q$, начальные моменты $M_{i_1\ldots i_n}$, центральные $\mu_{i_1\ldots i_n}$, матожидание $m_x(t)$. Держать их едиными во всех лекциях.
- Графики рисовать вручную как SVG по правилам скилла: `currentColor`, классы `acc`/`accf`, уникальные id маркеров.
- Выключные формулы разбивать через `aligned`, чтобы строка влезала в ширину телефона.
- Каждое отклонение от тетради (исправленные описки, догадки в неразборчивых местах) перечислять пользователю.

## Тесты и летучки

Для подготовки ответов используй скилл **prepare-test-answers** (`.claude/skills/prepare-test-answers/SKILL.md`). Основной сборник — `quizzes/tests.md`: все вопросы по лекциям в одном файле с оглавлением, HTML и PDF. `quizzes/quizNN.md` — отдельные ранее подготовленные материалы к летучкам.

- **С формулами.** Короткое определение, ключевая формула в LaTeX и смысл; без воды, доказательств и повторных выкладок. Для классификаций и перечней свойств можно использовать списки. Рисунки из `lectures/…/fig` — по необходимости.
- **Только то, что есть в конспекте.** Не писать, чего в конспекте нет (например, «физический смысл не записан»), — просто опускать.
- Темы берутся из запроса пользователя, лишних разделов не добавлять.

## Сдача изменений

- Если менялись `lectures/`, пересобрать `html/` и `pdf/`, проверить скриншотами, что формулы не обрезаны и графики читаются в светлой и тёмной теме, а PDF пролистывается.
- После правок `quizzes/` также пересобрать соответствующие HTML и PDF, проверить формулы на ширине телефона и ссылки оглавления.
